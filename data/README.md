# Sample dataset — column dictionary

> [!IMPORTANT]
> **All data here is synthetic.** Generated by `../scripts/generate_sample_data.py`
> with a fixed random seed. No real patients, providers, facilities, or health
> records. Any resemblance to a real person or organisation is coincidental.

Australian hospital operations across four facilities and twelve departments,
covering FY2024-25 and FY2025-26 (1 July 2024 to 30 June 2026).

---

## FactEncounter.csv — 6,000 rows

One row per patient encounter.

| Column | Type | Description |
| --- | --- | --- |
| `EncounterID` | Text | Unique encounter identifier (`ENC-2xxxxx`) |
| `DateKey` | Integer | Foreign key to `DimDate` (`yyyymmdd`) |
| `PatientKey` | Integer | Foreign key to `DimPatient` |
| `ProviderKey` | Integer | Foreign key to `DimProvider` |
| `DepartmentKey` | Integer | Foreign key to `DimDepartment` |
| `AdmissionType` | Text | Emergency, Elective, Transfer, Day Procedure |
| `LengthOfStayDays` | Integer | Days admitted. Zero for day procedures, except in Intensive Care where a two-day minimum applies |
| `ReadmittedWithin30Days` | Text | Yes / No |
| `WaitTimeMinutes` | Integer | Wait before treatment |
| `TotalCost` | Decimal | Cost of the encounter (AUD) |
| `ReimbursedAmount` | Decimal | Amount recovered (AUD) |
| `SatisfactionScore` | Integer | Patient rating, 1–10 |
| `Outcome` | Text | Discharged Home, Transferred, Discharged to Rehab, Deceased, Left Against Advice |

## Built-in signal

The generator seeds deliberate patterns so that measures show something
meaningful rather than noise:

| Pattern | Detail |
| --- | --- |
| Emergency waits are longer | Emergency 5–320 minutes; other types 0–60 |
| Long waits depress satisfaction | Mean score drops from ~8.1 to ~6.6 from 90 minutes |
| Long stays raise readmissions | ~14% above five days, versus ~6% otherwise |
| ICU skews long | Intensive Care encounters have a minimum stay of two days |
| Day procedures are cheap and same-day | Zero length of stay and lower base cost — but the Intensive Care two-day minimum overrides the zero, so 75 of 825 day procedures show a stay of 2 |
| Older patients carry more chronic conditions | ~55% in the 65+ bands, ~18% otherwise |
| Costs scale with stay | Base cost plus a per-day component plus noise |

python scripts/generate_sample_data.py
